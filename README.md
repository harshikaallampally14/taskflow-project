# TaskFlow — Productivity & Task Manager

A responsive, browser-based task management application supporting complete CRUD operations, category tagging, due-date tracking, drag-and-drop reordering, and `localStorage` persistence.

## Files
- `index.html` — Semantic HTML structure and TailwindCSS layout
- `style.css` — Custom CSS transitions, completion animations, and drag-and-drop states
- `app.js` — ES6+ state management (`tasks = []`), `localStorage` helpers (`saveToLocalStorage`, `loadFromLocalStorage`), CRUD, filtering, and search
